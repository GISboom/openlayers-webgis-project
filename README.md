# Vue3 OpenLayers WebGIS

基于 Vue3 + OpenLayers 开发的轻量级 WebGIS 系统。


## 技术栈

- Vue3
- Vite
- OpenLayers
- Element Plus
- Axios


## 已实现功能

- 天地图底图加载
- IP定位城市
- 行政区查询
- GeoJSON边界显示
- 点线面圆绘制
- SVG图标标注
- 城市搜索


## 项目运行


安装依赖

npm install


启动

npm run dev
